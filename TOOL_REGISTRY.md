## ID Reference
- Format: tool-NNN for base version, tool-NNNa through tool-NNNz for revisions
- Display: tool name + last revised date only — ID never shown to users
- Revision rule: logic change = new letter suffix. tool-001 → tool-001a → tool-001b etc.
- At tool-001z, next revision becomes tool-002 (may share same tool name/description)
- Deactivation: when a revision goes live, previous version must be removed from free-tools.html
- Sort order in free-tools.html: manually specified per deployment, not by ID
- Next available base ID: 002
